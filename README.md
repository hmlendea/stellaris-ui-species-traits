# Universum Infinitum - Species Traits

A Stellaris mod that adds 58 custom species traits, extends several trait families with additional tiers, and increases the maximum number of selectable traits.

## ✨ Capabilities

- Select from 58 custom positive and negative species traits covering combat, population, science, economy, habitability, and lifespan
- Use additional Very and Extremely tiers for established trait families
- Select up to seven biological or machine traits and six robot traits
- Recognise each added trait through dedicated icons and English descriptions

## 🚀 Usage

After installing the mod, use it through the Stellaris launcher:
1. Add **Universum Infinitum - Species Traits** to the active playset and enable it.
2. Start Stellaris and access species creation.
3. Select the additional traits subject to the available trait points and trait-count limits.

### Manual Installation

1. Download the desired archive from [GitHub Releases](https://github.com/hmlendea/stellaris-ui-species-traits/releases).
2. Extract the archive so that `ui-species-traits.mod` and `ui-species-traits/` reside directly in the Stellaris mod directory.
3. Enable the mod in the Stellaris launcher.
