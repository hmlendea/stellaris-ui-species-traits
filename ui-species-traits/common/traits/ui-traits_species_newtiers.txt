# Additional custom tiers for vanilla species traits.
# Each entry extends a vanilla trait line with stronger/weaker tier variants.
# Vanilla reference: Adaptive has +10% habitability and Extremely Adaptive has +20%.
# Tier scaling policy for modifier effects:
# - Very tier uses x1.5 of the base trait effect.
# - Extremely tier uses x2.0 of the base trait effect.
# - Discrete count modifiers are rounded away from zero to the nearest valid integer.
